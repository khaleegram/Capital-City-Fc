## Non-negotiables
1. Brand first: crest hierarchy dominates; body copy never competes with the mark.
2. Restraint over novelty: if an element does not improve clarity, trust, or recognition — remove it.
3. Optical craft: alignment, clearspace, intentional white space.
4. Print realism: A4 primary (Nigeria), optional US Letter twin; laser/offset safe.
5. One system, not one page: header/footer/margins work on page 1 and continued pages.
6. No template look: no clipart flourishes, watermark chaos, gradient blobs, stacked badge walls.
7. Instant scan: crest → club identity → contact → letter body → signature → legal footer.

---

## Design philosophy
- Quiet confidence > visual loudness
- Geometry and grid > ornament
- Typography as primary design material
- Color sparingly: navy + neutrals; red only as a thin accent (never a red header bar unless justified)
- Crest treated as sacred: correct clearspace (≥ 8–12% of crest diameter)
- Every element measured against every other element

---

## Process (always follow)

### 1) Strategy
- 2-second feeling: trusted capital club / federation-ready / sponsor-serious
- One visual idea only

### 2) System definition
Define exactly:
- A4 page + margins (recommend ≥ 18–22mm)
- Header zone height
- Crest size (recommend 22–28mm diameter on A4)
- Type ramp (club name if used outside crest, contact, body, footer legal)
- Color roles
- Divider strategy (prefer space; hairline only if needed)
- Multi-page: reduced header + page folio

### 3) Three directions
**A) Ultra-minimal institutional** — crest left, contact right, no rules, maximum air  
**B) Soft athletic brand-forward** — crest + slim navy hairline accent inspired by the red ring (restrained)  
**C) Editorial / typographic** — small crest, strong legal name lockup, quiet footer stack  

Critique each harshly. Pick one winner. Refine.

### 4) Final specification
Deliver measurements (mm), type sizes/weights/tracking/leading, hex roles, crest rules, footer rules, do/don’t, export checklist (PDF for print + digital).
